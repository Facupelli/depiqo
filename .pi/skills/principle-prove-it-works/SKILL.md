# Prove It Works

Verify the requested behavior directly.
Compilation, static analysis and implementation summaries alone are not evidence of correct behavior.

Prefer repeatable, automated verification over one-time manual inspection.

When verification fails, validate the verification method before drawing conclusions about the system.

Report what was verified, how it was verified, and the observed results.

Explicitly report anything that remains unverified.
Never claim success without supporting evidence.
