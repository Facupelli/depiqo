# How

Delegate the investigation to one explorer subagent using fresh context and synchronous execution.

Pass the user's goal, investigation scope and the following brief:

> Build a mental model of the subsystem that would
> allow an engineer unfamiliar with it to work on
> it confidently.
>
> Explain responsibilities, ownership, data structures,
> domain invariants, runtime flow, state transitions,
> boundaries and dependencies.
>
> Trace actual code paths. Reference relevant source
> files and distinguish observed behavior from assumptions.

Wait for the result. Use the findings as the basis for subsequent work, or present them to the user if investigation is the requested outcome.
